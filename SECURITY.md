# Security

This public repository accepts only non-secret agent guidance and synthetic test data.

Do not open a public issue for a suspected credential or private-data exposure. Use
GitHub's private vulnerability reporting for this repository. If a secret was exposed,
revoke it at its owning provider before reporting the repository cleanup.

The package must not contain credential values, private operational evidence,
deployment implementation or a direct infrastructure mutation path. Pull requests and
release artifacts are audited for this boundary.
